# DevNews - assignment 7

This is [Reactive Accelerator's assignment-7](https://github.com/Learn-with-Sumit/rnext/tree/assignment-7-batch-4). By completing this project i learned following topics :

- Parallel Routes
- Intercepting Routes
- Route Handler (GET,PATCH,DELETE)
- Middlewares (proxy)
- Not found page in Next.js
- Internationalization

## How to run

1. Clone this repo :
   ```sh
   git clone https://github.com/amimul-ihsan/lws-assignments
   cd lws-assignment
   git checkout assignment-7
   ```
2. Run this project :
   ```sh
   # with npm :
   npm run dev
   # or you can use pnpm :
   pnpm dev
   ```

## API Endpoints

Following API Endpoints are available **(API is memory only. Not really changes)** :

1. Get all news:

```
  /api/news  (GET)
```

2. Get single news:

```
   /api/news/{slug}  (GET,PATCH,DELETE)
```
